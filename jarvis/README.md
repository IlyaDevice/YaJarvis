# Джарвис на Rust

Новое ядро: один процесс, модули вшиваются при сборке, лёгкие плагины — на Lua.
Формат данных на колонке тот же, что у Go-версии (`settings.json`, `plugins.json`, память):
переход туда и обратно — просто подмена бинарника.

## Сборка

```sh
rustup target add aarch64-unknown-linux-musl
# C-код (ring для TLS) — zig; cc-rs передаёт rust-триплет, который zig не понимает:
# нужна обёртка, убирающая --target=… (см. scripts/rs-build.sh)
scripts/rs-build.sh 0.9.71      # → build/jarvis-arm64
cd jarvis && cargo test         # тесты на компьютере
```

## Оставшийся перенос

Подключения остаются выбираемыми модулями. Текущая совместимость с Go-плагинами —
переходный этап, а не завершение перехода на Rust + Lua.

- YouTube, Xiaomi и Smart Life ещё используют Go-модули. ChatGPT и VPN переключены на Rust на колонке; проверены реальный облачный голос, распознавание и Codex с инструментами. Старые native-реализации сохранены для отката.
- VPN: Rust-модуль TCP/WebSocket/TLS/REALITY/Vision проверен с независимым Xray. Для REALITY добавлен Chrome 133 с настоящим X25519+ML-KEM; SOCKS/VLESS UDP передаёт голос ChatGPT через VPN. UDP с Vision ещё требует XUDP.
- Автоматическая пересборка Rust-ядра при выборе модулей в панели ещё не перенесена; сейчас набор выбирается Cargo features.
- Текстовый чат, инструменты, OpenAI/Gemini/Grok Live, ElevenLabs Realtime и обычная связка STT → LLM → TTS реализованы. Остались быстрый STT, полный перебор резервных моделей/ключей и проверка всех облачных протоколов на живых аккаунтах.
- API ключей и пулов Gemini/ElevenLabs перенесены. Нужны оставшиеся API Xiaomi/Smart Life, обновления, обучения, статистики и предпросмотра.
- В музыке остаются состояние плеера Алисы и автоматическое предложение продолжения.
- Lua: HTTP с разрешёнными хостами/VPN, постоянное хранилище и таймеры реализованы; комплектные погода, валюты и кубик переведены с JS.
- Статус промежуточной версии и ограничения: [RUST-STATUS.md](../docs/RUST-STATUS.md).
