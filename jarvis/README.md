# Джарвис на Rust

Новое ядро: один процесс, модули вшиваются при сборке, лёгкие плагины — на Lua.
Формат данных на колонке тот же, что у Go-версии (`settings.json`, `plugins.json`, память):
переход туда и обратно — просто подмена бинарника.

## Сборка

```sh
rustup target add aarch64-unknown-linux-musl
scripts/rs-build.sh 0.9.71      # → build/jarvis-arm64
cd jarvis && cargo test         # тесты на компьютере
```
