# Лёгкие плагины Lua

Плагин работает в отдельной Lua 5.4 VM внутри процесса Rust, без отдельной программы.
Установка, включение, отключение, удаление и настройки используют обычную страницу «Плагины».
Для zip-установки положите `plugin.json` и `main.lua` в корень архива.
Рабочий пример: `plugins/examples/lua-coin/`.

`plugin.json`: `kind: "lua"`, `main: "main.lua"`, `api: 1`. Права:

- `tools` — регистрация инструментов модели;
- `commands` — обработка фраз без обращения к модели;
- `say` — функция `jarvis.say(text)` для озвучки.
- `network` — `jarvis.fetch(url, options)`; разрешённые хосты задаются массивом `network_allow` в манифесте;
- `storage` — `jarvis.store.get(key)` и `set(key, value)`; значение `nil` удаляет ключ;
- `timers` — `jarvis.timers.after(ms, callback)`, `every(ms, callback)` и `cancel(id)`.

Скрипт возвращает таблицу с необязательными полями:

```lua
return {
  init = function() jarvis.status('Готов') end,
  configure = function(settings) end,
  command = function(text)
    if text == 'моя команда' then return 'Ответ' end
    return nil -- фразу обрабатывают другие плагины и модель
  end,
  tools = {{
    name = 'my_tool', description = 'Описание',
    parameters = {type = 'object', properties = {}},
    handler = function(args) return 'Ответ' end,
  }},
}
```

`command` получает канонизированный текст: нижний регистр,
без знаков препинания и обращения «Джарвис». Возврат строки означает обработанную
команду; также поддерживается `{handled = true, answer = 'Ответ'}`.

`jarvis.settings` содержит значения настроек с умолчаниями из манифеста.
При изменении настроек таблица заменяется перед вызовом `configure(settings)`.
`jarvis.info` содержит город, часовой пояс, комнату, язык, модель колонки и имя ассистента.
`jarvis.log(text)` пишет в журнал, `jarvis.status(text)` показывает статус плагина.
`jarvis.json.encode(value)` и `jarvis.json.decode(text)` преобразуют JSON.

Включены стандартные `table`, `string`, `math`, `utf8` и базовые функции Lua.
Прямого доступа к ОС, файлам, процессам, package/require, debug и загрузке байткода нет.
HTTP доступен только с правом `network` и непустым `network_allow`: точный хост,
origin (`https://example.org`) или поддомены (`*.example.org`). Каждый redirect
проверяется заново; HTTPS не понижается до HTTP, заголовки не пересылаются на другой
origin. Маршрут использует настройку VPN подключения «Плагины»; ошибка VPN не
приводит к прямому запросу. Ответ ограничен 1 МиБ, поддерживается текст UTF-8.
`fetch` возвращает `{status, ok, body}`; JSON разбирается через `jarvis.json.decode`.
`options` допускает `method`, строковый `body` и таблицу строковых `headers`.
Хранилище ограничено 256 КиБ, сохраняется атомарно отдельно от файлов установленного
плагина и переживает его обновление. На плагин допускается 64 таймера; период
повторного таймера — от 100 мс. Отключение останавливает таймеры и HTTP.
`jarvis.now()` — Unix-время в миллисекундах; `urlencode(text)` кодирует параметр URL,
`normalize(text)` приводит текст к формату быстрых команд, `random(min,max)`
возвращает целое из системного источника случайности.
На VM выделяется до 8 МиБ памяти, Lua-вызов ограничен двумя секундами вычисления и
20 секундами общего времени с HTTP,
очередь — 16 запросами. Ограничение времени проверяется Lua hook; длинные операции
стандартной C-библиотеки завершаются до следующей проверки hook.
Имена встроенных инструментов ядра и дубликаты инструментов запрещены.

## Своя текстовая модель

Добавьте в манифест `"provides": ["llm"]` и `"min_core": "0.9.84"`. Экспортируйте одну функцию:

```lua
return {
  chat = function(request)
    local last = request.messages[#request.messages]
    return "Получено: " .. last.content
  end,
}
```

Установите ZIP в «Подключениях». В настройках ассистента выберите плагин в поле «Текстовая модель из плагина». На главной отправьте сообщение. Плагин работает в переписке и классической голосовой цепочке. Для голоса выберите и настройте отдельный модуль распознавания и озвучки.

- `request.messages` содержит сообщения с полями `role` и `content`. Ядро передаёт инструкции ассистента и вопрос. При вызове инструмента добавляются сообщения `assistant` и `tool` этой реплики.
- `request.tools` содержит доступные инструменты в формате Chat Completions. Для обычного ответа верните строку.
- Для вызова инструмента верните `{text = "", tool_calls = {{id = "call_1", name = "имя", arguments = "{}"}}}`. `arguments` принимает строку с объектом JSON. Ядро проверит имя по выданному списку, выполнит инструмент и снова вызовет `chat` с результатом. Доступно до пяти вызовов `chat` на реплику и до 16 инструментов за вызов.
- Для своего HTTP API добавьте право `network` и внесите точный origin сервера в `network_allow`. Ключ объявите настройкой с `"type": "password"` и читайте через `jarvis.settings`.

Для подключения к другой модели возьмите URL и ID из документации поставщика. Передайте `request.messages` в формате его API, а текст ответа верните из `chat`.

Обычная сборка включает Lua. Для сборки без интерпретатора и его зависимостей:

```sh
cd jarvis
cargo build --release --target aarch64-unknown-linux-musl --no-default-features
```

Lua является исполняемым кодом внутри процесса. Ограничения VM не заменяют
проверку исходников распространяемого плагина.
