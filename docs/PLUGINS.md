# Плагины YaJavis

На чистой прошивке мастер первого входа предлагает официальные плагины. Выбирать, настраивать или удалять плагины также можно в разделе «Подключения».

- [Официальные пакеты](RUST-MODULES.md)
- [SDK для устанавливаемых Rust-пакетов](NATIVE-PLUGINS.md)
- [Lua API и формат пакета](LUA.md)
- [API текстовых моделей](LUA.md#своя-текстовая-модель)
- [Примеры Lua-плагинов](../plugins/examples/lua-coin)

В ZIP Lua-плагина положите `plugin.json` и входной `main.lua`. Панель принимает ZIP локально или скачивает пакет из релиза автора. Чтобы плагин появился в каталоге, задайте репозиторию тему `yajarvis-plugin`. Для категории добавьте тему вроде `yajarvis-info`. Имя архива для общего пакета `jarvis-plugin.zip`, для платформенного `jarvis-plugin-<arch>.zip`.

Если для обновления работающего плагина нужен полный перезапуск колонки, добавьте `"reboot_on_update": true` в `plugin.json`. Колонка запустит новую версию после загрузки. При массовом обновлении она перезагрузится один раз в конце. При первой установке или обновлении выключенного плагина перезагрузка не нужна.

Настройки и данные подключений хранятся на колонке. Обновление пакета плагина сохраняет его данные.
