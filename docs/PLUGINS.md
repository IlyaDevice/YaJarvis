# Плагины YaJavis

Пользователь устанавливает и включает нужные подключения в панели колонки. Официальные модули интеграций написаны на Rust, небольшие плагины могут работать на Lua.

- [Rust-модули](RUST-MODULES.md)
- [Lua API и формат пакета](LUA.md)
- [Примеры Lua-плагинов](../plugins/examples/lua-coin)

В ZIP Lua-плагина положите `plugin.json` и входной `main.lua`. Установщик в панели принимает ZIP локально или загружает пакет из релиза GitHub. Чтобы плагин появился в каталоге, задайте репозиторию тему `yajarvis-plugin`. Для категории добавьте дополнительную тему, например `yajarvis-tools`. Имя архива релиза `plugin-<id>.zip` соответствует идентификатору в манифесте.

Настройки и данные подключений хранятся на колонке. Обновление пакета плагина сохраняет его данные.
