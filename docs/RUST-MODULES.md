# Rust-модули и Lua

| Формат | Выполнение |
| --- | --- |
| `module` | Rust-код в процессе ядра. Cargo feature включает нужный модуль и его зависимости. |
| `lua` | Lua-скрипт в ограниченной среде внутри ядра. Устанавливается архивом ZIP. |

Rust-модули: ChatGPT, OpenAI, Gemini, Grok, ElevenLabs, Home Assistant, Яндекс Умный дом, Smart Life, Xiaomi, VPN, YouTube и обучение слова. При установке из панели модуль получает свою папку настроек. Отключение останавливает его задачи и запросы OAuth и API.

Каталог показывает все официальные модули. Если код модуля уже есть в ядре, панель подключает его сразу. В другом случае она выбирает наименьшую подходящую сборку из официального релиза и применяет её после перезапуска. При обновлении сохраняются установленные модули. Релиз поставляет полную и минимальную сборки. Для отдельной комбинации модулей соберите ядро с нужными Cargo features.

```sh
cd jarvis
cargo build --release --target aarch64-unknown-linux-musl --features homeassistant,yandexhome,vpn
cargo build --release --target aarch64-unknown-linux-musl --no-default-features
```

Сборка по умолчанию содержит ядро и Lua. Флаг `--no-default-features` убирает Lua. Установщик на компьютере по умолчанию ставит полный пакет. `jarvis core-info` показывает версию, архитектуру и список включённых в сборку модулей. В работающей системе этот список доступен на `/healthz`.
