# Официальные пакеты

Чистая прошивка содержит базовые функции колонки и поддержку Lua. ChatGPT, OpenAI, Gemini, Grok, ElevenLabs, Home Assistant, Яндекс Умный дом, Smart Life, Xiaomi, VPN, YouTube и обучение слова устанавливаются отдельными пакетами для архитектуры колонки.

Панель скачивает выбранный архив, проверяет контрольную сумму и запускает плагин. При удалении процесс останавливается, его бинарник и рабочая папка удаляются. Для смены состава плагинов ядро перезапускать не нужно.

Команда `jarvis core-info` показывает версию, архитектуру и пустой список встроенных модулей у штатной сборки. Установленные плагины перечислены в `/api/plugins`.
