# Rust + Lua: промежуточная версия 17.11.2026

Это промежуточная сборка. Наличие реализации и локального теста не означает,
что все облачные сервисы уже проверены на колонке с реальными аккаунтами.
Go-ядро не менялось. Старые native-плагины поддерживаются на время переноса.

## Последующие исправления

- `0.9.77-rs`: REALITY с Chrome 133, настоящим X25519+ML-KEM-768 и Brotli.
  Добавлены SOCKS UDP ASSOCIATE/VLESS UDP и маршрут ICE/DTLS/RTP для Rust ChatGPT.
  Прямой обход выбранного VPN не используется. UDP с Vision пока отключён до XUDP.
  Исправлено событие озвучки текста ChatGPT: `session.context.append`.
  Исправлен разбор Codex SSE: завершающее `output:[]` больше не стирает уже
  полученный текст и вызовы инструментов. Это проверено на реальном ответе с `web_search`.
  Таймер воспроизведения Opus сохраняет исходный такт пакетов: опоздания таймера
  больше не прибавляются к каждому следующему пакету и не накапливают отставание.
  Двунаправленный WebRTC-тест проверяет звук и допустимую задержку напрямую и через VPN.
  Пройдены 115 тестов пакетов workspace со всеми features, включая независимые Xray и Go TLS
  с обязательным гибридным обменом. По реальной VPN-ссылке проверены HTTPS,
  облачный звонок (1,5–2,6 с до готовности в проверках), распознавание
  синтезированной речи «сколько будет два плюс два» и голосовой ответ «четыре».
  Эти замеры сделаны с компьютера; задержка обычных разговоров на колонке может отличаться.
- `0.9.76-rs`: ElevenLabs Realtime Mini/Max реализован в модуле `elevenlabs`:
  создание сессии, одноразовый токен, WebSocket, PCM, инструменты и перебивание.
  Локальный сервер проверяет HTTP/WebSocket и обмен аудио; реальный облачный
  разговор этим тестом не подтверждён. Настройки текущего ассистента не меняются.
- В обычном режиме STT → LLM → TTS исправлен перехват произвольных фраз
  музыкальным обработчиком. Нераспознанная команда проходит дальше к модели.

- `0.9.74-rs`: перенесены `/api/stats`, `/api/logs` и системные показатели журнала.
  История за сутки хранится в памяти, логи читаются ограниченным окном с фильтром.
  На колонке подтверждены живые значения и пополнение истории.
- Микрофон ChatGPT отправляется каждые 20 мс. Из накопленного звука сокращаются
  только длинные тихие паузы; тихая речь и конец паузы сохраняются.
  Подготовка независимых подключений выполняется параллельно.
- `0.9.75-rs`: перенесены примерка LED, загрузка и возврат модели активации.
  Проверенная модель применяется в цикле микрофона без перезапуска ядра.
  Загрузчик отклоняет неверные размеры, параметры и веса до запуска модели.
- HTTP-клиенты облачных Rust-модулей сохраняют соединения в пределах одного
  сетевого маршрута и сбрасываются при его смене или отключении модуля.
- Добавлены замеры готовности ChatGPT и первого звука. Ошибка открытия больше
  не должна теряться при событии закрытия, пришедшем раньше ответа плагина.
  Это исправление диагностики, не подтверждение устранения всех задержек сервиса.

## Установка этой версии

- На колонку установлено Rust-ядро `0.9.77-rs`, ARM64 musl, около 10 МБ.
- Запущены Rust-модули Home Assistant, Яндекс Умный дом, OpenAI, Gemini, Grok
  и ElevenLabs, ChatGPT и VPN. Уже установленный плагин валют обновлён на Lua.
- ChatGPT и VPN переключены на Rust-модули с прежней REALITY-ссылкой `fp=chrome`.
  На колонке звонок открылся за 1,95 с; UDP-сокеты голоса подключены к локальному релею.
  После исправления Codex проверен весь путь из панели: текст → ответ «проверка» →
  реальная озвучка через Rust VPN. Первый голос пришёл через 2,71 с от открытия
  голосовой сессии; время самого текстового запроса в этот замер не входит.
  Проверены SHA-256 файла и работающего процесса, микрофон, логи и история телеметрии.
  Аккаунт, ссылка, маршруты и профили сохранены. RSS ядра после проверки около 9,7 МиБ;
  это один снимок, без учёта ОС и оставшихся native-процессов, не замер пика нагрузки.
  YouTube, Xiaomi/Smart Life и обучение остаются прежними плагинами.
- Пройдены 115 тестов пакетов workspace со всеми features и тест
  подключения микрофона при загрузке. Проверена сборка ядра без default features.
- Проверены SHA-256 установленного бинарника, HTTP панели, health, API журнала,
  памяти и музыки. После перезапуска микрофон снова подключился,
  модель активации загружена, встроенные модули запущены.
- После запуска Rust новых сообщений `modules: migration: GitHub ответил 404` нет.
- Реальный каталог HA не проверен: настроенный сервер HA отказывает в соединении
  и с компьютера, и через Rust-модуль. Все остальные облачные голосовые провайдеры
  и выполнение команд на устройствах этой проверкой не подтверждены.
- Сохранены резервная копия данных и прежний бинарник для отката/совместимости.
  Автоматическая сборка набора модулей и полный отказ от Go ещё не завершены.

## Реализовано, но перенос ещё не закончен

- VPN на Rust: VLESS TCP/WebSocket, TLS, REALITY, Vision и SOCKS5.
  Есть тесты с независимым Xray-сервером. REALITY поддерживает Chrome 133
  (`fp=chrome`/`chrome133`) с X25519+ML-KEM, GREASE, перестановкой расширений и Brotli.
  SOCKS5 UDP ASSOCIATE передаёт пакеты через VLESS UDP; UDP с Vision пока требует XUDP.
  Нет Chrome для обычного TLS, остальных браузерных fingerprints,
  ML-DSA, gRPC/XHTTP и остальных неподдерживаемых режимов из README модуля.
  Профиль Chrome закреплён на версии 133. Параметры ссылки не удаляются молча.
- ChatGPT по подписке: вход устройства, обновление токена, Codex SSE,
  WebRTC, кодек Opus, запросы к бэкенду и постоянный ID чата.
  Локальный тест проверяет SDP, данные, звук и запрос к бэкенду.
  Проверен реальный облачный звонок через Rust VPN с REALITY/Chrome: входящая речь,
  распознавание, ответ модели и Opus. WebRTC использует SOCKS UDP, если модуль VPN
  явно поддерживает его; со старым провайдером остаётся только TCP ICE без прямого обхода.
- OpenAI, Gemini, Grok: текст с инструментами и потоковые голосовые сессии.
  ElevenLabs: STT, TTS и каталог голосов. Обычный голосовой режим
  STT → LLM → TTS реализован. Проверка всех реальных облачных протоколов ещё нужна.
- Музыка: Rust управляет командами, очередью, приглушением и API;
  YouTube пока выполняется прежним native-плагином.

## Осталось

- Перенести YouTube, Xiaomi и Smart Life с Go.
- Проверка ElevenLabs Realtime на реальном аккаунте, быстрый STT и полное резервирование моделей/ключей.
- Состояние музыки Алисы и автоматическое предложение продолжения.
- Автоматический подбор и замена Rust-сборки при выборе модулей в панели.
  Сейчас код выбирается Cargo features при сборке на компьютере.
- Оставшиеся API обновлений, обучения, статистики, предпросмотра,
  управления пользовательскими голосами и части подключений.
- Проверить новые подключения, прерывание речи, длительную работу и нагрузку
  на реальной колонке. Старые замеры памяти нельзя считать замерами этой сборки.

Lua и Opus используют встроенные C-библиотеки; захват и проигрывание звука
также опираются на штатные компоненты колонки. Перенос на Rust относится к
ядру и логике подключений, а не к переписыванию ОС и всех сторонних библиотек.
